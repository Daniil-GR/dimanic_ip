Подтверждение добавления

Будут добавлены выбранные IPv4 без проверки MTProto. После настройки VPS запустите проверку доступности. Существующие записи не отправляются на перезапись.
Подтверждение удаления
Будут изменены реальные записи в выбранном режиме. DNS-кэш обновляется с учётом TTL.
